# Aurion Health Advisory | Modern React + Vite Architecture

> **Sovereign & Institutional Healthcare Advisory Practice**  
> Cairo • Riyadh • Dubai  
> Live Canonical Site: [https://drassermedhat.github.io/AurionHealth/](https://drassermedhat.github.io/AurionHealth/)

This repository is the modular, modern **React 18 + TypeScript + Vite + Tailwind CSS** implementation of the Aurion Health Advisory institutional web platform, fully architected for **Lovable (`lovable.dev`)**, **Bolt.new**, **v0.dev**, and **Vercel**.

## ⚡ 1-Click Launch & Import Options

### 1. Open Instantly in Bolt.new
Run this entire project with live code editing and instant preview directly in your browser:
[![Open in Bolt.new](https://bolt.new/button)](https://bolt.new/github/DrAsserMedhat/aurion-health-react)

Or visit:
```
https://bolt.new/github/DrAsserMedhat/aurion-health-react
```

### 2. Connect & Edit with Lovable (`lovable.dev`)
1. Log in to [Lovable.dev](https://lovable.dev).
2. Go to **Settings / GitHub Sync** or choose **Import from GitHub**.
3. Select `DrAsserMedhat/aurion-health-react`.
4. Lovable will automatically parse the components, styles, and data models for 2-way AI visual editing.

### 3. Deploy to Vercel in 1 Click
1. Open [Vercel Dashboard](https://vercel.com/new).
2. Import `DrAsserMedhat/aurion-health-react`.
3. Click **Deploy** (zero configuration required; Vite preset is detected automatically).
